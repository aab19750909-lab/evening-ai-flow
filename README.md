# Vibe Code Studio

Создай Hero-секцию для лендинга-портфолио специалиста по вайбкодингу. Используй стиль загруженного референса.

Возьми: цветовую палитру, композицию, стиль типографики, визуальные акценты, общее настроение интерфейса.

Заголовок: "Создам цифровой инструмент под Вашу задачу за один вечер".

Подзаголовок: “ Создаю AI-продукты через вайбкодинг: быстро собираю MVP, лендинги и веб-приложения с помощью современных AI-инструментов”.

В правой части Hero разместить визуальный элемент в стиле референса — фрагмент интерфейса или дашборда.

Создай кнопки: "Записаться на бесплатную консультацию (Telegram) " и "Записаться на бесплатную консультацию (e-mail)".

Для обеих кнопок добавь состояния: hover (кнопка становится чуть темнее и приподнимаются), focus (появляется обводка), loading (на кнопке появляется спиннер и текст "Обработка...")».

Адаптируй под мобильные устройства.
